Senior UI still rests on fundamentals. Most “advanced” bugs are composition mistakes in disguise.

## Elements vs components

A component is a function. An element is a description of what to render. Confusing the two leads to accidental remounts and broken state.

## Composition over configuration

Prefer `children` and small focused components over a prop matrix that tries to encode every layout variant.

```tsx
function Panel({ children }: { children: React.ReactNode }) {
  return <section className="panel">{children}</section>
}
```

## Keys and identity

Keys tell React which child is which across renders. Index keys are fine for static lists; unstable keys reset state and thrash the DOM.

## Context with restraint

Context is for **rarely changing, widely read** values (theme, locale, auth). High-frequency values belong in stores or props — otherwise you re-render half the tree on every tick.
